# 企业宣传独立站验收标准

适用项目：惠州学院 AI 与 IP 协会 × 惠创智联科技服务有限公司

## 1. 品牌与内容

- 首页首屏在 5 秒内说明“是谁、做什么、如何参与”。
- 协会与企业身份清晰，不混淆公益展示、人才培养与企业服务。
- 标题、按钮、报名入口和二维码文案一致，不出现占位文字。
- 对外发布内容不包含账号、密钥、临时文件或未经授权素材。

## 2. 文字与版式

- 在 360、390、768、1024、1440、1920 像素宽度下无横向溢出。
- 核心标题按语义换行，不允许末行只剩一个汉字或标点。
- 正文移动端字号不低于 14px，主要按钮文字不低于 14px。
- 标题、正文、说明文字形成明确的三级信息层级。
- 同类卡片的边距、基线和高度保持一致。

## 3. 图片与视觉

- 人物主体不得被相邻色块、文字层或容器边界遮挡。
- 信息型图片完整显示；氛围型图片才允许使用封面裁切。
- 图片具有明确宽高，首屏主图优先加载，其余图片延迟加载。
- 所有有信息价值的图片提供准确替代文字。
- 图片加载失败时不得破坏主要内容结构。

## 4. 手机体验

- 360–430px 宽度下导航、筛选、页签、弹窗和固定按钮可正常操作。
- 点击目标高度不低于 44px，常用操作可单手触达。
- 手机端关闭非必要持续动画、复杂模糊和大面积缩放效果。
- 页面滑动无明显掉帧，内容进入视口时不发生大幅布局跳动。
- 弹窗不超出屏幕，二维码完整显示并可保存或识别。

## 5. 功能与兼容性

- Chrome、Edge及微信内置浏览器访问首页均返回 HTTP 200。
- CSS、JavaScript和全部主要图片请求成功。
- 活动筛选、身份页签、移动导航、报名弹窗均通过点击测试。
- 页面无 JavaScript 运行错误和失败的资源请求。
- 键盘焦点、按钮语义和图片替代文字满足基础可访问性要求。

## 6. 性能与发布

- 首屏只主动加载必要资源，非首屏图片使用懒加载。
- 移动端不运行非必要的滚动入场动画和持续跑马灯动画。
- 资源使用相对路径，允许部署在 GitHub Pages 子目录。
- 正式发布只修改指定项目目录，并保留独立 Git 提交记录。
- 上线后必须用 HTTPS 公网地址再次完成完整功能验收。

## 放行原则

存在以下任一问题不得上线：核心标题孤字、人物主体被遮挡、手机横向溢出、主要功能失效、主要图片加载失败、控制台报错、微信访问非 200。
